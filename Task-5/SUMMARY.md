## Summary

This project performs Exploratory Data Analysis (EDA) on the Titanic dataset using Python, Pandas, Matplotlib, and Seaborn. The analysis includes data cleaning, descriptive statistics, handling missing values, and visualizing the data through count plots, histograms, boxplots, scatter plots, heatmaps, and pairplots.

The analysis reveals that gender and passenger class were the most significant factors influencing survival. Female passengers and those traveling in first class had a higher probability of survival. Most passengers were between 20–40 years old, and the fare distribution showed a positive skew with a few high-value outliers.
