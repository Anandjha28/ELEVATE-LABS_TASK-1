# 📊 Task 6 - Sales Trend Analysis Using Aggregations

## 📌 Objective
The objective of this task is to analyze monthly sales trends using SQL aggregation functions. The analysis focuses on identifying monthly revenue, order volume, average order value, and top-performing months based on sales.

---

## 📂 Dataset
**Dataset Used:** Olist Brazilian E-commerce Public Dataset (Kaggle)

Tables Used:
- orders
- order_payments

---

## 🛠️ Tools Used
- PostgreSQL
- pgAdmin 4
- SQL

---

## 📈 SQL Concepts Covered
- SELECT
- JOIN
- SUM()
- COUNT(DISTINCT)
- AVG()
- EXTRACT()
- DATE_TRUNC()
- GROUP BY
- ORDER BY
- LIMIT
- Aggregate Functions

---

## 📋 Analysis Performed

### 1. Monthly Revenue Analysis
Calculated the total revenue generated each month using the SUM() function.

### 2. Monthly Order Volume
Counted the number of unique orders placed every month using COUNT(DISTINCT).

### 3. Average Order Value
Calculated the average payment value for each month.

### 4. Top 3 Months by Revenue
Identified the three months with the highest total revenue.

### 5. Top 3 Months by Order Volume
Identified the three months with the highest number of orders.

### 6. Overall Revenue
Calculated the total revenue generated from all orders.

### 7. Overall Orders
Calculated the total number of unique orders.
